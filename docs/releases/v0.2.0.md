# IUCE Reservas v0.2.0 — Calendario, panel administrativo y rework visual

[![SonarCloud Quality Gate](https://sonarcloud.io/api/project_badges/measure?project=ShockyDEV_IUCE-Reservas-TFG&metric=alert_status)](https://sonarcloud.io/summary/new_code?id=ShockyDEV_IUCE-Reservas-TFG)

Segunda release pública del Trabajo de Fin de Grado **IUCE Reservas**, sistema web de gestión de reservas de espacios académicos para el Instituto Universitario de Ciencias de la Educación (IUCE) de la Universidad de Salamanca.

Esta release recoge el resultado de los **sprints 5, 6 y 7** del proyecto. Hereda toda la funcionalidad de [v0.1.0](https://github.com/ShockyDEV/IUCE-Reservas-TFG/releases/tag/v0.1.0) (autenticación passwordless, catálogo de espacios, motor de reservas, aprobación administrativa y notificaciones por email) y añade el calendario visual, la recurrencia, los bloqueos administrativos, el panel administrativo completo, el audit log y un refactor visual integral basado en `shadcn/ui`.

---

## Funcionalidad nueva desde v0.1.0

### Sprint 5 — Recurrencia y bloqueos de calendario

- **Reservas recurrentes** con tres patrones: `WEEKLY`, `BIWEEKLY` y `MONTHLY`. El motor expande la solicitud en instancias individuales agrupadas por `recurrenceGroupId` y omite automáticamente las que colisionan con otras reservas o con bloqueos.
- **Salvaguarda** de 52 ocurrencias máximas por solicitud para evitar recurrencias accidentales muy largas.
- **Modelo `BlockedSlot`** con API completa `GET / POST / DELETE` para que el personal administrativo bloquee franjas por mantenimiento, vacaciones o eventos institucionales.
- Validación reforzada en `POST /api/reservations`: rechaza la creación si solapa con cualquier reserva en estado `PENDING` o `APPROVED`, o con cualquier bloqueo activo.
- Componentes `WeekCalendar` (vista semanal por espacio) y `DashboardCalendar` (vista mensual compacta integrada en el panel del usuario).

### Sprint 6 — Panel administrativo y audit log

- Dashboard `/admin` con tarjetas de **pendientes / aprobadas / rechazadas / total**, ranking de **espacios más reservados (30 días)** y **audit log reciente**.
- Endpoint `GET /api/admin/stats` con totales por estado, serie diaria de los últimos 30 días, ranking de espacios, top de usuarios y últimas 20 entradas del audit log.
- API de gestión de usuarios (`GET /api/admin/users`, `PATCH /api/admin/users/[id]`) con protección jerárquica: solo otro `SUPER_ADMIN` puede modificar a un `SUPER_ADMIN`.
- API de gestión de espacios (`POST /api/admin/spaces`, `PATCH /api/admin/spaces/[id]`, `DELETE /api/admin/spaces/[id]`) con validación Zod y **soft delete** (`isActive=false`) que conserva las reservas históricas.
- Modelo `AuditLog` y helper `logAudit()` con un catálogo cerrado de ocho acciones: `RESERVATION_APPROVED`, `RESERVATION_REJECTED`, `BLOCKED_SLOT_CREATED`, `BLOCKED_SLOT_DELETED`, `USER_ROLE_CHANGED`, `SPACE_CREATED`, `SPACE_UPDATED` y `SPACE_DEACTIVATED`.
- Refactor `requireAdmin()` (helper en `src/lib/admin-guard.ts`) que centraliza la guarda de rol y reduce las duplicaciones detectadas por SonarCloud en los siete endpoints administrativos.

### Sprint 7 — UX y Mobile (rework visual a shadcn/ui)

- Migración del sistema de componentes a `shadcn/ui` (`Button`, `Card`, `Input`, `Textarea`, `Badge`) con la paleta corporativa **USAL/IUCE** y la familia de tokens `brand`, `success`, `warning` y `danger`.
- Helper `cn()` (`clsx` + `tailwind-merge`) y dependencias auxiliares: `class-variance-authority`, `lucide-react` y `react-hot-toast`.
- **Navbar global** con menú adaptativo por rol (acceso al panel administrativo solo si el usuario es `ADMIN` o `SUPER_ADMIN`) y soporte hamburguesa para móvil.
- **Footer institucional** con bloque corporativo (USAL · IUCE) y enlaces a las normas de uso.
- **Sistema de toasts** integrado en el layout raíz con coloreado coherente con la paleta y posición inferior centrada.
- Rediseño visual completo de: landing pública, `/auth/signin` (layout dividido), `/dashboard`, catálogo `/spaces`, ficha `/spaces/[id]`, formulario `/spaces/[id]/reserve` y panel `/admin`.
- Soporte **responsive** desde 375 px con tap targets de 44 px mínimo y navbar adaptativa.
- Suite de **tests unitarios de componentes** con `@testing-library/react` + `jsdom`.

### Pulido posterior al cierre del Sprint 7 (26 may)

Como cierre del bloque admin antes de esta release, se añaden tres pantallas administrativas cuya API ya estaba implementada en Sprints 5 y 6 pero a las que aún no se había dado UI:

- `/admin/spaces` — CRUD completo de espacios con alta, edición y desactivación (soft delete).
- `/admin/users` — listado con cambio de rol inline respetando la jerarquía `SUPER_ADMIN`.
- `/admin/blocked-slots` — listado, creación y eliminación de bloqueos administrativos.
- Adicionalmente, se corrige la presentación del logo institucional en el banner azul de `/auth/signin`.

## Levantar el proyecto en local

> Requisitos: Node.js 20+, Docker y Docker Compose, Git.

```bash
# 1. Clonar el repositorio en la versión de esta release
git clone https://github.com/ShockyDEV/IUCE-Reservas-TFG.git
cd IUCE-Reservas-TFG
git checkout v0.2.0

# 2. Instalar dependencias
npm install

# 3. Variables de entorno
cp .env.example .env
# Edita .env si quieres enviar emails reales con Resend; por defecto
# los emails se loguean a consola y los magic links no salen del servidor.

# 4. Levantar PostgreSQL en Docker
docker-compose up -d

# 5. Aplicar el esquema y datos iniciales
npm run db:push
npm run db:seed

# 6. Arrancar el servidor de desarrollo
npm run dev
```

La aplicación queda disponible en [http://localhost:3000](http://localhost:3000).

Con `NEXT_PUBLIC_USE_MOCK_AUTH=true` (valor por defecto en `.env.example`), la pantalla `/auth/signin` muestra tres botones de acceso rápido (`Admin`, `Usuario`, `Super Admin`) que permiten evaluar la aplicación completa sin disponer de una cuenta institucional `@usal.es` y sin configurar Resend.

### Comandos útiles

```bash
npm run test           # Ejecuta los 65 tests unitarios
npm run build          # Compila para producción (Next.js standalone)
npm run db:studio      # Abre Prisma Studio (UI de la base de datos)
```
